PhotoAgent 1.4.1 уточняет порядок очистки временных фотографий.

- JPEG удаляются строго от более старых к новым по времени записи UTC среди всех папок заданий. После достижения лимита очистка по объёму останавливается.
- Свежие снимки в папке старого задания сохраняются. Вместе с выбранным JPEG удаляются его квитанции; возраст этой пары определяется JPEG.
- Просроченные фото также обрабатываются от старых к новым. Служебные остатки учитываются по собственному времени записи.
- Активные задания и читаемые 1С файлы остаются защищены. При нехватке доступного места новый снимок возвращает ошибку.
- В `transfer_expired` добавлено `expired_files` — накопленный список удалённых JPEG. 1С прекращает повторы только для этих фото и продолжает загрузку остальных. Без этого поля уведомление означает очистку всего задания, как в 1.4.0.

Ограничения по умолчанию сохранены: один календарный месяц и 100 МБ. Обновлён MD для программиста 1С.

Пройдены 164 автоматические проверки, включая перемешанные по возрасту фото в разных папках, частичную очистку задания, удаление JPEG с квитанциями и обновление уведомления при блокировке файла.

Lite-установщик без .NET. Требуется Windows 10 с установленным .NET Framework 4.8 или новее. Перед обновлением закройте PhotoAgent через «Выход». Установщик без подписи издателя.
