PhotoAgent 1.5.0 добавляет пересъёмку одного выбранного кадра по команде из 1С.

- Основной режим `capture_document` не изменён: лицо → паспорт → прописка, с отдельным JSON по готовности каждого фото. Прежние команды и формат обмена 1.4.1 сохранены.
- Новая отдельная команда `recapture_photo` принимает `photo_type: "lomo" | "passport" | "registration"` и новый `request_id`. Открывается только выбранный этап с назначенной ему камерой. После одного кадра окно закрывается.
- Готовый JPEG передаётся через `transfer\<request_id>`. Создаётся одно `.photo.0001.json`, затем `.done` с `photo_count: 1`, одним элементом `photos` и совместимым `files`.
- Заменяется только выбранный файл рабочей папки и текущего месяца архива. Остальные фотографии, включая файлы только в архиве, сохраняются.
- Некорректный или отсутствующий `photo_type` даёт понятный `error` без открытия камеры. Крестик до снимка возвращает «Некорректное завершение обработки задания», `photo_count: 0` и `photos: []`, сохраняя прежний кадр. Ожидание камеры и `busy` работают штатно.
- При отказе кеша по объёму прежние рабочий и архивный кадры сохраняются. Файл предыдущего запроса не меняется во время медленного чтения из 1С.
- Таймаут нового конфига увеличен до `captureTimeoutSec: 300` — пять минут на всё задание. Ожидание камеры приостанавливает отсчёт. **При обновлении существующий параметр сохраняется**; если осталось `120`, измените его на `300` вручную и перезапустите агент.
- Обновлён MD для программиста 1С: новая команда, загрузка и замена выбранного снимка, защита от запоздалой загрузки прежней версии.

Выпуск проверяется 180 автоматическими проверками: 31 обмена, 23 архива и конфигурации, 31 кеша, 30 окон и камер с имитацией устройств, 65 установки, обновления и удаления с сохранением данных. Реальные USB-камеры, RDP и обработку 1С нужно проверить на рабочем месте.

Lite-установщик без .NET. Требуется Windows 10 с установленным .NET Framework 4.8 или новее. Перед обновлением закройте PhotoAgent через «Выход», установите под тем же пользователем поверх прежней версии. Настройки, назначения камер и архив сохраняются. Установщик без подписи издателя.
