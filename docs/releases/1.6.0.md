PhotoAgent 1.6.0 разделяет штатную съёмку на два независимых задания из 1С.

- `capture_photo` («Фото») — только один кадр ломосдатчика, `photo_type: "lomo"`. Проверяется и открывается только назначенная камера ломосдатчика; камера документов может быть отключена или не задана.
- `capture_documents` («Документы») — паспорт, затем прописка: `sequence: 1/passport` и `2/registration`. Используется только камера документов; камера ломосдатчика не проверяется и не требуется.
- При запуске PhotoAgent не перечисляет камеры, не проверяет подключения и не открывает мастер настройки. Уже заданные назначения сохраняются; первоначальная настройка выполняется вручную через меню трея до начала задания.
- Каждый запрос имеет новый GUID, отдельную папку `transfer\<request_id>`, нумерацию с единицы и собственный `.done`. Документы можно снять до фото ломосдатчика, автоматического перехода к другой группе нет.
- Передача JPEG по мере готовности сохранена. У «Фото» один `photo_ready` и `photo_count: 1`; у «Документы» два уведомления и `photo_count: 2`. Загрузка первого кадра документов начинается до окончания съёмки прописки.
- Паспорт и прописка используют один непрерывный предпросмотр. Отключение нужной камеры показывает «подключите камеру», подключение продолжает то же задание; ожидание приостанавливает таймаут.
- Рабочие и архивные JPEG других типов, включая файлы только в архиве, сохраняются. При закрытии второго этапа готовый паспорт остаётся в уведомлении и итоговом манифесте с `status: error`.
- `capture_extra`, `recapture_photo` и формат обмена 1.4.1 сохранены. Старая `capture_document` по-прежнему выполняет три кадра для совместимости; в новой штатной обработке использовать две отдельные команды.
- Таймаут — по пять минут на отдельный запрос для нового конфига, без сброса между паспортом и пропиской. Существующие настройки не перезаписываются. Ограничения transfer и архива сохранены.
- Обновлены MD для программиста 1С и инструкции установки: два действия, независимые запросы и прогресс, проверка только нужной камеры, ручная первоначальная настройка.

Выпуск проверяется 196 автоматическими проверками: 33 обмена, 23 архива и конфигурации, 31 кеша, 44 запуска, окон и камер с имитацией устройств, 65 установки, обновления и удаления с сохранением данных. Проверяются запуск без камер и назначений, каждый отдельный режим без другой камеры, оба порядка запросов, медленная загрузка предыдущего JPEG, общий видеопоток документов, отмена и квота. Реальные USB-камеры, RDP и конкретную обработку 1С проверить на рабочем месте.

Lite-установщик без .NET. Требуется Windows 10 с установленным .NET Framework 4.8 или новее. Перед обновлением завершите PhotoAgent через «Выход» и установите под тем же пользователем поверх прежней версии. Назначения камер, настройки и архив сохраняются. Установщик без подписи издателя.
