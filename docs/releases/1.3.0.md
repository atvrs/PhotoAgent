PhotoAgent 1.3.0 — поэтапная передача фотографий в 1С, архив в месяцах и облегчённый установщик.

### Загрузка фото в 1С

- После каждого основного и дополнительного снимка публикуется отдельный JSON со статусом `photo_ready`. 1С может загружать первый JPEG, пока оператор снимает следующие кадры.
- Снимки для передачи хранятся отдельно для каждого задания; новая съёмка документа не изменяет файл, который 1С ещё читает.
- Итоговый `.done` сохранён и содержит `photo_count` и `photos`, включая готовые кадры при частичной отмене.
- Сохранены опрос заданий через RDP, ожидание отсутствующей камеры и непрерывный поток камеры документов между паспортом и пропиской.

Для поэтапной загрузки нужно обновить обработку 1С по приложенному `PhotoAgent_1C_Integration_RU.md`. Её исходников в репозитории нет. Прежняя обработка продолжает работать через итоговый `.done`.

### Архив

- Новый параметр `archiveRetentionMonths`, по умолчанию `60`: текущий и 59 предыдущих месяцев.
- Срок считается по имени папки `YYYY-MM`, независимо от даты её создания в Windows.
- Старая настройка в днях мигрирует автоматически. Исходный конфиг сохраняется в `config.json.bak`; назначения камер сохраняются.
- Отдельный лимит `archiveMaxGb` остаётся действующим; `0` отключает очистку по размеру. Настройки архива не очищают `transfer`.

### Установка

Скачайте `PhotoAgent_Setup_1.3.0_Lite.exe` либо ZIP с инструкциями. Установщик не содержит и не скачивает .NET; требуется уже установленный .NET Framework 4.8 или новее на рабочей станции Windows 10.

Перед обновлением завершите съёмку и закройте старую программу через «Выход». Запускайте установщик под тем же оператором. Настройки, архив, рабочие фото и очередь передачи сохраняются; конфигурация проходит описанную миграцию. Установщик без подписи издателя.

### Проверка

На Windows Server 2022 пройдены 127 автоматических проверок: 23 — обмен, 19 — архив и миграция, 20 — окна и камеры с имитацией устройств, 65 — установка, обновление, удаление и сохранение данных. Реальные USB-камеры, RDP и обработку 1С проверить на рабочем месте. Остановка Lite-установщика на системе без .NET отдельно не испытывалась.

Контрольные суммы файлов релиза приведены в `RELEASE_SHA256SUMS.txt`. Сведения о сборке находятся внутри ZIP.
