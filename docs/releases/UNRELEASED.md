# Подготовлено для следующего выпуска

- Значение по умолчанию `captureTimeoutSec` увеличено со 120 до 300 секунд — пяти минут на всё задание, включая серию дополнительных фото.
- Между снимками таймер не сбрасывается. Ожидание отсутствующей камеры приостанавливает отсчёт.
- Уже заданный `captureTimeoutSec` сохраняется при обновлении. Для текущей установленной версии пользователь меняет его вручную на `300` и перезапускает PhotoAgent.
- Опубликованные релизы и их установщики не изменяются. Новый релиз этим изменением не выпускается.
