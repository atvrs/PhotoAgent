# Установка PhotoAgent 1.1.0

Пакет предназначен для рабочей станции **Windows 10 x86/x64** с подключёнными USB-камерами. Запускать установщик нужно на рабочей станции, под учётной записью оператора. На сервер 2008 R2 через RDP его устанавливать не нужно.

## Состав

- `PhotoAgent_Setup_1.1.0.exe` — автономный установщик. Внутри программа, библиотеки AForge и официальный установщик Microsoft .NET Framework 4.8.
- `INSTALL_RU.md` — эта инструкция.
- `SHA256SUMS.txt` — контрольная сумма EXE.
- `BUILD_INFO.txt` — версия, исходный коммит и сведения о сборке.

Интернет для установки не требуется. Драйверы конкретных камер должны быть установлены в Windows отдельно. Программа и установщик не подписаны сертификатом издателя.

## Первая установка

1. Подключите обе камеры и убедитесь, что Windows их определила. Закройте приложения, использующие камеры.
2. Запустите `PhotoAgent_Setup_1.1.0.exe` обычным двойным щелчком под оператором. Выбирать «Запуск от имени администратора» для всего установщика не нужно.
3. Оставьте предложенную папку `%LOCALAPPDATA%\Programs\PhotoAgent`. Установщик создаст ярлыки в меню «Пуск», в `C:\psa_photos` и, по выбранной опции, на рабочем столе. Автозапуск регистрируется для текущего пользователя.
4. Если .NET Framework 4.8 отсутствует, запустится вложенный установщик Microsoft с отдельным запросом прав администратора. Если потребуется перезагрузка, выполните её. После успешной установки PhotoAgent запустится при следующем входе в Windows.
5. Запустите PhotoAgent и назначьте камеру ломосдатчика и камеру документов. Значок программы появится в области уведомлений.
6. Через меню значка выполните «Тест камеры ломосдатчика» и «Тест камеры документа». Затем проверьте одно полное задание из 1С — лицо, паспорт и регистрация.

Данные и обмен сохраняются в `C:\psa_photos`. Оператору нужны права изменения этой папки и её подпапок. Если установщик сообщает об отсутствии доступа, администратор должен предоставить права этому пользователю, после чего следует повторить обычный запуск установщика.

## Обновление существующего PhotoAgent

1. Дождитесь завершения текущего задания из 1С.
2. Через меню значка старого PhotoAgent выберите **«Выход»**.
3. Запустите новый установщик под тем же оператором. Удалять предыдущую версию перед обновлением не требуется.
4. Установщик обновит программу и ярлыки, заменит путь автозапуска. Существующий `C:\psa_photos\config.json` и фотографии сохранятся. Повторное назначение камер обычно не требуется.
5. Если раньше использовалась переносная версия, запускайте теперь установленную программу через новый ярлык. Старую копию EXE не запускайте. Другие созданные вручную задания планировщика и ярлыки автозагрузки нужно проверить отдельно.

В 1С остаются те же папки, команды и формат ответа. Положительный `.done` для `capture_document` появляется после всех трёх снимков. Ожидание отсутствующей камеры и ошибка при закрытии окна крестиком включены. Повторные два снимка камеры документов используют один непрерывный видеопоток.

## Проверка после установки

- В «О программе» отображается версия `1.1.0`.
- Первое и второе фото документов последовательно показывают живой предпросмотр.
- Если камеры нет, видно «подключите камеру»; после подключения задание продолжается. Таймер PhotoAgent при ожидании приостановлен, таймер ожидания в 1С независим.
- При закрытии окна крестиком 1С получает `status: "error"` и сообщение «Некорректное завершение обработки задания».
- После выхода и нового входа оператора в Windows программа запускается автоматически.

## Удаление

Завершите текущее задание, выберите «Выход» в меню значка, затем удалите PhotoAgent через «Приложения и возможности» Windows или меню «Пуск → PhotoAgent → Удалить PhotoAgent».

Удаляются установленная программа, её ярлыки и запись автозапуска. **Настройки, фотографии, архив, журналы и папки обмена в `C:\psa_photos` остаются.** Удаление PhotoAgent не удаляет .NET Framework и старые переносные копии программы.

## Сборка разработчиком

На Windows нужны MSBuild, NuGet и Inno Setup 6. После восстановления `packages.config` и сборки Release запустите `installer\Build-Installer.ps1`. Скрипт скачает официальный автономный .NET 4.8 и проверит подпись Microsoft. Результат появится в `installer\output`.

GitHub Actions собирает приложение и установщик, выполняет тесты обмена и камер, затем проверяет установку, запуск из пути с пробелами, повторную установку и удаление с сохранением данных. Проверки камер используют имитацию устройств; окончательная проверка USB-камер и RDP выполняется на рабочем месте.
